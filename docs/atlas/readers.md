## bf6_atlas.gd (273) — ATLASTEXTURE flipbook headers
`RES_TYPE 0x957C32B1`, `HEADER_SIZE 92`: flags u16@0, w u16@2, h u16@4, mips u8@6, border f32@8/@0xC, chunk GUID@0x10 (**RAW HEX keying, 85/85 vs 0/85 dashed**), FIFTEEN u32 mip sizes @0x20 (eight truncates 21/85). LeftRightTiles = only left half is lighting base.

## bf6_bundle.gd (208) — bundle CAS segments + asset tables
`SALT 0x7065636E`; magics STANDARD `0xED1CEDB8` / KELVIN `0xC3889333` / ENCRYPTED `0xC3E5D5C3` (hard error). Magic endianness probed BE-then-LE. Segment blob: records @blob+32; `F_FNVFILE 0x80` picks 8-byte vs 4-byte id/cas framing; flag 0 = reuse previous CasFileId. **Every declared offset is relative to byte 4.** Header 0x24 (STANDARD) vs 0x20; STANDARD carries TotalCount×SHA1. RES table = four parallel arrays (names/sizes, types, meta 16B, rids u64). Chunk table stride 24 (plain-LE guid + logicalOffset/Size). Names plain NUL-terminated. `assets()` :199 is dead (source walks members directly to avoid 450k Array allocs).

## bf6_cas.gd (258) — CAS block reader + Oodle
Block header two BE dwords: flags=d0>>24, dsize=d0&0xFFFFFF, codec=d1>>24, **guard nibble (d1>>20)&15 == 7 always**, csize=d1&0xFFFFF. `CODEC_NONE 0`, OODLE {0x11,0x15,0x17,0x19}. Two non-corruption cases: segment 0 stored RAW (`allow_raw`, discovered via guard failure), and multi-block refs (single-block fast path `csize == size-8`, else walk — missing this read 42/82 barrack prefabs empty). Handle cache MAX 192.

## bf6_depot.gd (325) — ShaderBlockDepot
NOT the SWBF2/Frosty container. header_a u64 == 16; key table @16 `{u64 key, u64 recPtr(absolute)}`; **table length recovered by dereferencing the first record's dataOffset** (= blob start = key table end). Records `{dataOffset, contentHash, size}` ascending, exactly tiling the blob area (contiguity IS the terminator; residual gap > 16 = hard error). Blob: u32 count then packed 16-byte entries `{u64 paramHash, u32 typeHash, u16 flags, u16 nameHashHi}`, no alignment; texture entries (`TH_TEXTURE 0xcc84d53d`): u8 n × 32 bytes {root guid A, **FILE guid B — B resolves**}; inline arrays HLSL cbuffer packed (16-byte stride, last element unpadded). `SCALAR_SIZE` table :47-59 — unknown type hash = hard error. **THE JOIN: MeshSet section state key u64 @ section+0x130 → key_to_record. NOT the MVDB SurfaceShaderGuid.** Slot hashes (full 32 bits) :63-105 incl. `SLOT_EMISSIVE_LIT 0x407055fd` (the real lamp glow) and the smoke/decal families. `key_hex` :144 exists because GDScript int64 renders top-bit keys negative under %016x.

## bf6_ebx.gd (539) — RIFF-EBX partitions
No @tool (deliberate: class_name so no root-relative preload). Types reader is INJECTED. EFIX order :120-164: partition guid, type guids, signatures, exported count, instance offsets, pointer offsets (skipped), resource-ref offsets, imports (2×16B). Instance guid = 16 bytes BEFORE the image, first `exported` only. `ELEM_SIZE` :37-44 — **Bool arrays are FLAT BYTES (stride 1)**; the u32 fallback dropped 5,762 instances (building facades). **PointerRef = SIGNED i32 in an 8-byte slot** (:424-441; 885/886 negative resolve); low bit = import (idx>>1), else internal at (pos+idx)-payload. Array convention: s32 rel @pos, data at (pos+4)+rel-8, s32 count there. `_cstring` s64 rel, -1 empty. A field landing outside the file must not kill the instance (:376 — 395 street lights). `int_pointer` :302 — reflection says int32 but it holds a PointerRef (light spatial components, `0x11F57ECA`). Gravestone comment block :333-365 (removed LinearTransform fast path) misdescribes the live function.

## bf6_materialtree.gd (434) — terrain blocks 7 + 8
Block 7 header 0x24 (dim u32@0, world min/max f32, nodeCount@0x18, levelMax@0x20); block 8 same fields, stream @0x28, no footer. **Node framing: TWO leading flag bytes + a TRAILING hasChildren.** Both-flags-set: s32 payloadSize + payload + dim×u16 row sizes (sum == payloadSize is a free check). **Nibble-RLE rows** (:212-245, byte-for-byte the engine decoder @0x145728250): low nibble first; first byte = initial value; byte == current ⇒ next byte is run length in 2-texel groups; row must produce dim texels AND consume exactly its bytes. Pair footer: u32 n + n×u32 + u32 background; exact-size identity is the walk check. Pair entry: framing 0x80 low byte / 0x06 top byte; X nibbles primary/secondary (15 = none); Y-lo = which list (1 node base, 0 full, 2 linked). Block 8 bit 0 clear = urban hard-ground descriptor — **never cut geometry with it**. Rasterise coarse-first; **the node's OWN base list wins** (global-list reading wrong on 23/35 maps); spatial matching by bounds, never key equality.

Section: material name s64@+0x08, bpv u8@+0x1A, materialId u16@+0x1C, stride u8@+0x1E, primCount@+0x20, startIndex@+0x24, vertexOffset@+0x28, vertexCount@+0x2C, **declA @+0x64, declB @+0xC8**, **state_key u64 @+0x130**. Decl: 16×4B elements [usage, format, offset, stream] + 16×2B streams [stride, class] @+64 + counts @+96/97. ## bf6_terrain.gd (614) — the heightfield
Typed blocks from 0x22: u8 type + i32 size; **0xFF terminates** (empirical). Types: 0 heights, 2 density, 1 splat, 4/5 masks, 7/8 rasters. Block header 0x48: xs s32@0, worldSizeY f32@0x10, minMaxDepth@0x1C, occluderDepth@0x20, densitySide@0x24, **NodeBorderWidth s32@0x44 (not a constant 4)**. Identity check: densitySide == (xs-1)/4+1. `_stack()` :47 generates the magic 340/1156/1225 numbers. Chunk directory sits AFTER the 0xFF terminator (not a typed block); guids keyed **RAW HEX** (dashed found 0/100). ## bf6_texture.gd (395) — TextureResource → Image
**WIDTH @22, HEIGHT @24** (fb_texture.py's names were swapped; settled by decoding 60 non-square textures both ways: 60-0). `streamflag = byte 21 bit 0x10`: SET → embedded = chain minus mip0, streamed = mip0 alone; CLEAR → embedded = whole chain. FMT BF6→DXGI :72-75 with two measured departures: **64 → 95 (BC6H_UF16, not SF16 — the sky went white at mean 12,000 otherwise)** and **60 → 77 (BC3 LINEAR, not sRGB — flat normals measured 0.502 not 0.735)**. `dims_for` header-exact suffix-sum, **× slices** (cubemaps). **The cap works because of the chunk split: every level ≥2048 is in the STREAMED chunk, everything below in EMBEDDED (1,053/1,053)** — capping = asking for the other chunk, no decompress. `decode` tries nominated chunk then other, both guid spellings; validates lengths; reads EVERY slice.

## bf6_toc.gd (255) — merged SuperBundle TOCs
**Everything big-endian; every offset relative to byte 556.** Header :82-93; flags 0x01 BaseBundles / 0x02 BaseChunks / 0x04 CompressedNames; `unk1 == unk2 == dataOff` enforced. **Huffman names: i32 pairs, last pair = root, negative = leaf (sym = -v-1), bits LSB-first within consecutive BE words, sym 0 terminates.** A TOC can set CompressedNames and carry no names (HRES packages) — not corruption. Bundle map stride 16 (INLINE 1<<30, IN_MEMORY 1<<31, SIZE_MASK); chunk map stride 20, **guid stored REVERSED**, value 0xFFFFFFFF = removed; `data_pos` in **4-BYTE UNITS** relative to DataOffset; then the same FnvFile-width branch as bundle. Loose-chunk map = whole chunk; bundle chunk entries = resident sub-range.

## bf6_types.gd (347) — type layouts from the exe
Reads the PE FILE, never the process. **SP and MP exes carry DIFFERENT type databases.** `typeinfo` section search native via `BF6Oodle.find()` (29.6ms vs 3.2s = 108×). **A VA with the high bit set arrives NEGATIVE in GDScript** (signed 64-bit) — comparisons rely on that symmetry; never clamp to zero. Type layout relative to guid file offset fo: nameHash@fo-8, flags@fo-4, size@fo-2, align@fo+32, fieldCount@fo+34, superClass@fo+40, **pFieldInfos @fo+48 (Class) or @fo+88 (Struct)**. FieldInfo stride 24: nameHash u32, flags u16, offset u32@+8, typeVA u64@+16. **offset 0xFFFF = "no serialized slot" sentinel, NOT an offset** (22/43 fields on the street light; killed the instance 395×). Superclass dedup by nameHash (identity), never by offset. Array element type: try slots [48,40,56,32,24], first plausible TypeInfoData wins.

## bf6_walk.gd (1014) — the placement walk
Role GUIDs :33-44 (LEVEL_ROOT, 3×SUBWORLD, LAYER, SMG, PREFABs). Field hashes :46-65; **measured: `0xB608BEEE` carries the blueprint path, not the type DB's `0x1B4A547C` MeshAsset (null on every member)**. **LinearTransform members ADDRESSED BY NAME HASH, never sorted order** (`right 0xC478CC3B`@0, `up 0xBF151EF9`@16, `forward 0x695D12A4`@32, `trans 0xBC4B07B4`@48) — numeric sort yields forward,trans,up,right and transposes the whole map. Transforms kept as four Vector3s, NOT Transform3D (row-basis, non-uniform; Godot Basis assumptions don't apply); worldXf = parent * local at exactly one place (BlueprintTransform). **The light join: 86.9% of lights have IDENTITY transforms; the placement sits on component `dcac04fc-…` pointing back via int-that-is-a-PointerRef `0x11F57ECA`; components resolved BEFORE the instance loop** (component comes after its light). `DESTRUCTION_BRANCH` 10 guids :122-144 — walking through cost geometry twice AND masked the leaf fallback (the street light, 395×). `flat_bools` :267: Bool arrays are flat bytes; reflection has no elemVA for primitives; first ceil(n/4) u32s hold all n bytes; missing = VISIBLE. Per-instance ObjectVariation :396 — mesh identity is (name, variation). **Leaf emission :800: recurse, and if rows didn't grow, emit a leaf row** (1,381/1,407 partitions produced zero rows before). Scope inheritance :570: a prop's depot belongs to the SUBWORLD that mounted it (directory ancestry alone = 54.7%; other-subworld fallback = 99.5%). `_type_matters` :515 an equivalence, wanted types checked FIRST (lights declare no traversal fields). Cache VERSION 4 (v2 scope, v3 entities, v4 light spatial transform); placements fingerprint = SHA-256 over mesh path + 12 floats per row in order (counts can't catch a transposed basis).
